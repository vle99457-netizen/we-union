# WE V3.0 Specification Package

This folder contains the reviewable source of truth for the WE V3.0 website requirements.

- `spec.md` — product, page and non-functional requirements
- `research.md` — method and repository evidence
- `plan.md` — phased implementation plan
- `tasks.md` — requirement-linked execution backlog
- `data-model.md` — entities and invariants
- `contracts/openapi.yaml` — draft service boundaries

Binary DOCX/PDF/PPTX/XLSX deliverables are stored outside the Git repository to avoid repository bloat. Requirement IDs are consistent across all formats.
